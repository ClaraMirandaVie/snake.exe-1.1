# snake.exe-1.1

## About
SNAKE.exe is a personal development project created to explore web development, JavaScript programming, game mechanics and interface design.
**play snake.exe(https://claramirandavie.github.io/snake.exe-1.1/)**

## Features
### Classic Mode
The traditional Snake experience, featuring three difficulty levels:
- **Easy:** A more relaxed experience.
- **Normal:** The classic balance between speed and challenge.
- **Hard:** Faster gameplay for players looking for an extra challenge.

### Gameplay
- Classic snake movement and mechanics.
- Collect food to grow your snake.
- Earn points for each food collected.
- Random food generation.
- Collision detection with walls and the snake's own body.
- Increasing difficulty through gameplay.

### Customization
- Multiple snake skins (4).
  
### Audio
- Background music.
- Sound effects.
- Audio settings and controls.

### Statistics and Progress
- Personal statistics.
- High scores and records.
- Game progress saved locally.

### Additional Features
- Pause and resume gameplay.
- Restart games whenever you want.
- Settings and customization options.
- Local data persistence using LocalStorage.

|---|---|

## Technologies
- **HTML5** — Game structure.
- **CSS3** — Styling, layout and visual identity.
- **JavaScript** — Game mechanics, interactions and functionality.
- **LocalStorage** — Local data persistence.
No external game engine required.

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/ClaraMirandaVie/snake.exe-1.1.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
Alternatively, play directly through the browser using the link above.
